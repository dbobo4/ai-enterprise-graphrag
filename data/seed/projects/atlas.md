# Project Atlas — Ticketing platform

Project Atlas modernises the internal support ticketing platform at HelioWorks Kft. The project lead is Nóra Varga. Its target go-live date is 2026-11-15. The team is replacing legacy ticket routing with a central API and a searchable service catalogue.

The project description records leadership, purpose and timeline. Supplier assignments and incident root causes are documented separately so a question linking them needs evidence from more than one file.
