# Project Atlas Archive — Records migration

Nóra Váradi leads Project Atlas Archive, the records migration programme, with a target go-live of 2027-02-12. The programme code is OP-36. The work moves signed delivery records from shared folders into managed archive storage. Its budget covers scanning preparation, rejected-batch handling and a small restore exercise.

The intake team sorts paper bundles by site and receipt date before scanning. Each bundle receives a batch label that stays with the physical envelope. Pages that cannot be read are quarantined instead of being silently omitted. The records coordinator decides whether a replacement scan is required or whether the original page must be inspected at the site.

The migration will start with closed delivery batches. Active disputes remain in their current restricted folder until their owner approves transfer. Operators must preserve the signature page and the attachment order. The archive catalogue stores the receipt number and retention start event; it does not replace the accounting approval attached to an invoice.

During the rehearsal, a reviewer will restore a randomly selected bundle to a temporary folder and compare it with the paper envelope. A successful storage upload is only the first acceptance step. The team must also show that the receiving permissions and retention date survived the move. Any failed comparison produces a rejection entry for the whole bundle.

Operations has reserved a scanning desk away from the dispatch counter. Drivers should continue using the normal receipt tray rather than leaving documents beside the scanner. The programme office will review the rejected-batch queue every Monday. Additional scanners will be considered only if the first two weeks demonstrate a sustained capacity shortage.

Each migration batch has an operator and a reviewer, and the same person cannot release a batch they scanned. Release requires a complete page count, a readable signature and confirmation that restricted records retain their approved access group. Missing paperwork stays in a locked holding tray with a named owner. The team will resolve these exceptions before scheduling collection of the original envelopes.

The storage handover includes an agreed restore contact and a list of failed transfers awaiting investigation. Operations will compare accepted batch volumes with storage charges before approving the monthly invoice. Capacity estimates include rescans and temporary restore copies, which must be cleared after review. If scanning falls behind, the coordinator will defer a whole closed batch rather than split custody of its pages across locations.
