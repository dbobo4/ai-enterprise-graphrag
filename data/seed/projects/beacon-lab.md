# Project Beacon Lab — Finance network sandbox

Péter Varga leads Project Beacon Lab, the finance network sandbox, with a target go-live of 2026-12-15. The programme code is F-27. The isolated environment supports reconciliation exercises using sample payment files. It has no approved connection to the production payment gateway and carries no authority to release real transactions.

Finance will prepare a small set of balanced and deliberately incomplete sample files. The test coordinator records who reviewed each mismatch and which sample was restored. A failed exercise should leave enough information to reproduce the accounting decision without retaining a personal copy of the whole input file. Staff will use individual practice accounts.

Network access is limited to the training room and the designated analyst desks. The team has reserved one afternoon each week for supervised practice. Other departments can attend an observation session after Finance approves the agenda. Equipment used by a visiting employee must be inspected before it is connected to the isolated segment.

Acceptance checks include a rejected file, a restored session and the removal of temporary output files. A test run that balances correctly does not prove that a production change is safe. The final sign-off confirms that the learning environment is ready for the agreed exercises. Any proposal to connect another service requires a new scope decision.

The programme will review the number of unused practice accounts after the first month. Trainers can request a smaller sample pack for shorter sessions. The analyst team will record recurrent training questions and update the instruction sheet. Room bookings and refreshments use the normal office process and do not extend the sandbox support window.

Finance owns the sample pack and approves any replacement file before a session. Account numbers and payment references in training data must be invented; a production extract cannot be made acceptable by hiding its filename. The trainer resets the working directory between groups and checks that an interrupted exercise has not left another participant's output visible. Session notes record the accounting issue without copying the payment file.

The network engineer keeps the sandbox connection list and reviews changes with the Finance coordinator. Monitoring alerts go to the designated support contact during supervised sessions; outside that window the room remains closed. The handover must include instructions for isolating a misconnected workstation and restoring the clean exercise image. Additional licences or monitoring capacity need a budget decision before another analyst group is admitted.
